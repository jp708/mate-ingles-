# English Listening Test Game 🎧✨

Este es un juego de práctica interactivo diseñado especialmente para niños en etapa de aprendizaje de inglés.

## Contenido Incluido:
1. **Numbers (10-100 & Teen vs Ty):** Práctica para diferenciar números confusos (14 vs 40, 17 vs 70, etc.).
2. **Telling the Time:** Relojes analógicos en formato SVG dinámico (o'clock, half past, quarter past, quarter to).
3. **Does He/She Like...?:** Preguntas de escucha sobre alimentos, animales y gustos con respuestas objetivo.

## Características Técnicas:
- **Responsive Design:** Adaptado para teléfonos, tablets y computadoras.
- **Web Speech API:** Genera pronunciación clara en inglés sin requerir archivos de audio externos.
- **Feedback Interactivo:** Animaciones de acierto con confeti, sonido de victoria y alerta roja de intento en caso de error.
- **Sin Dependencias Complejas:** Puedes abrir el archivo `index.html` directamente en cualquier navegador moderno.
